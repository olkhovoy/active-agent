# Website Design: Block 1 - The Hook

## **Утвержденный заголовок:**
**"Единственное сознание, бесконечные отражения"**  
*(A single consciousness, infinite echoes.)*

---

## **Визуальный дизайн**

### **Фон**
- **Цвет:** Темный, минималистичный (#0a0a0a или #111111)
- **Текстура:** Едва заметная, медленно движущаяся сетка или туманность
- **Анимация:** Плавное движение частиц/волн от центра к краям (скорость: 1-2 пикселя в секунду)

### **Центральный визуальный элемент**
- **Основной объект:** Яркий, светящийся шар в центре экрана
  - Цвет: белый с голубым свечением (#ffffff с #4fc3f7 glow)
  - Размер: 120-150px в диаметре
  - Эффект: мягкое пульсирование (анимация: 3-4 секунды на цикл)
- **Эхо-эффект:** От центрального шара исходят призрачные волны
  - Цвет: полупрозрачный белый (#ffffff с opacity 0.3-0.7)
  - Форма: человеческие силуэты, которые появляются и растворяются
  - Анимация: волны расходятся от центра, силуэты формируются на 1-2 секунды, затем растворяются
  - Частота: новый силуэт каждые 2-3 секунды

## **Интерактивные элементы**

### **Кнопка 1 - Основная (CTA)**
```html
<button class="cta-primary">
  <span class="btn-text">Читать полную статью</span>
  <span class="btn-icon">→</span>
</button>
```
- **Стиль:** Крупная, яркая кнопка (#4fc3f7 фон, белый текст)
- **Действие:** Ссылка на PDF на viXra или GitHub
- **Анимация:** Легкое свечение при наведении

### **Кнопка 2 - Вторичная**
```html
<button class="cta-secondary">
  <span class="btn-text">Узнать, как это работает</span>
  <span class="btn-icon">↓</span>
</button>
```
- **Стиль:** Прозрачная кнопка с белой рамкой
- **Действие:** Плавный скролл к Блоку 3 (диаграмма итеративного цикла)
- **Анимация:** Плавное появление рамки при наведении

---

## **Технические требования**

### **Адаптивность**
- **Desktop:** Полноэкранный блок (100vh)
- **Tablet:** Адаптация элементов под меньший экран
- **Mobile:** Упрощенная анимация, увеличенные кнопки

### **Производительность**
- **Анимации:** CSS3 transitions + requestAnimationFrame для плавности
- **Оптимизация:** WebGL для сложных визуальных эффектов (опционально)
- **Загрузка:** Lazy loading для тяжелых элементов

### **Доступность**
- **Контрастность:** Минимум 4.5:1 для текста
- **Навигация:** Поддержка клавиатуры
- **Screen readers:** Семантическая разметка
