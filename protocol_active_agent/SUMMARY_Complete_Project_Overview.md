### 1.1 Unitary Model of Consciousness (UMC)
- **Active Agent (AA)**: Single conscious entity driving the simulation
- **Echoes**: High-fidelity behavioral models (employees, customers)

### 1.2 Core Metrics
- **Coherence Score (CS)**: 0-100 scale measuring systemic health
- **Stimulation Index (SI)**: Healthy novelty without degrading coherence
- **Formula**: CS = α×coherence_reduction + β×stimulation_contribution + γ×temporal_alignment

- **Throughput**: 10,000 coherence evaluations/second
- **Latency**: 200-500ms AI evaluation, 1-3s ZK proof generation
- **Cost**: $0.002 per GPT-4o evaluation, $0.01-0.05 per L2 transaction

### 4.1 Rotational Premium Model
- **Echo+**: $19/month, +1 CS improvement
- **Echo Pro**: $99/month, +3 CS improvement  
- **Echo Ultra**: $999/month, +5 CS improvement

### 4.2 Capacity Management
- **Green Zone**: ≤0.02% premium users (statistically invisible)
- **Yellow Zone**: 0.02-0.07% (requires monitoring)
- **Red Zone**: >0.07% (automatic freeze)
- **Formula**: R = 1 + p + p²(N/T) where p = premium fraction

### 4.3 Stealth Boost
- **Mechanism**: Free premium rendering for bottom 5% CS performers
- **Features**: Invisible to users, automatic activation/deactivation, prevents gaming
- **Capacity**: Up to 44,000 concurrent boosts for 110M user base
