# Система оценки ERC-20 токенов

Комплексная система для автоматического обнаружения, оценки и мониторинга ERC-20 токенов с целью надежного отделения легитимных проектов от скам-токенов.

## 🎯 Основные цели

- **Обнаружение новых токенов** через CoinGecko API и сканирование Ethereum блокчейна
- **Комплексная оценка** токенов по критериям безопасности, ликвидности и сообщества
- **Непрерывный мониторинг** новых токенов и их метрик
- **Выявление скам-паттернов** и потенциальных рисков
- **Генерация отчетов** для принятия обоснованных решений

## 🔍 Основные компоненты

### 1. TokenDiscoveryAgent

**Назначение**: Автоматическое обнаружение новых ERC-20 токенов

**Возможности**:
- Поиск через CoinGecko API по рыночной капитализации и возрасту
- Сканирование Ethereum блокчейна через Etherscan
- Фильтрация по минимальным критериям (держатели, транзакции)
- Удаление дубликатов и валидация адресов

**Пример использования**:
```python
from token_discovery_agent import TokenDiscoveryAgent

agent = TokenDiscoveryAgent()

# Обнаружение через CoinGecko
tokens = agent.discover_new_tokens_coingecko(
    min_market_cap=1000000,  # $1M
    max_age_days=30
)

# Обнаружение через Etherscan
tokens = agent.discover_new_tokens_etherscan(
    min_holders=100,
    min_transactions=1000
)
```

### 2. AdvancedTokenEvaluator

**Назначение**: Комплексная оценка токенов по множественным критериям

**Критерии оценки**:
- **Безопасность (40%)**: верификация контракта, аудит, мультисиг, таймлок
- **Ликвидность (30%)**: общая ликвидность, распределение по DEX, концентрация
- **Сообщество (20%)**: GitHub активность, социальные сети, документация

**Уровни риска**:
- `CRITICAL` (0.8-1.0): Высокий риск, вероятно скам
- `HIGH` (0.6-0.8): Повышенный риск, требует внимания
- `MEDIUM` (0.4-0.6): Средний риск, нейтрально
- `LOW` (0.0-0.4): Низкий риск, относительно безопасно

**Рекомендации**:
- `INVEST`: Низкий риск, рекомендуется для инвестиций
- `HOLD`: Средний риск, можно держать
- `AVOID`: Высокий риск, лучше избегать
- `SCAM`: Критический риск, вероятно скам

**Пример использования**:
```python
from advanced_evaluator import AdvancedTokenEvaluator

evaluator = AdvancedTokenEvaluator()

assessment = evaluator.evaluate_token(
    contract_address="0x...",
    token_data={
        'name': 'Token Name',
        'symbol': 'TKN',
        'market_cap_usd': 1000000
    }
)

print(f"Рекомендация: {assessment.recommendation}")
print(f"Уровень риска: {assessment.risk_level}")
print(f"Общий балл: {assessment.overall_score:.2f}")
```

### 3. TokenMonitor

**Назначение**: Непрерывный мониторинг и индексация токенов

**Возможности**:
- Сканирование новых блоков Ethereum
- Обнаружение создания новых токенов
- Отслеживание изменений ликвидности
- Хранение в SQLite базе данных
- Автоматическая очистка старых данных

**Структура базы данных**:
- `tokens`: Основная информация о токенах
- `token_events`: События (создание, переводы, изменения ликвидности)
- `token_holders`: Информация о держателях

**Пример использования**:
```python
from token_monitor import TokenMonitor

monitor = TokenMonitor("tokens.db")
monitor.init_database()

# Запуск мониторинга
await monitor.start_monitoring()

# Получение токенов по уровню риска
high_risk = monitor.get_tokens_by_risk(risk_threshold=0.7)
```

### 4. TokenEvaluationSystem

**Назначение**: Интеграция всех компонентов в единую систему

**Возможности**:
- Оркестрация полного цикла оценки
- Управление конфигурацией
- Генерация сводных отчетов
- Экспорт данных в различных форматах
- Статистика и аналитика

**Пример использования**:
```python
from token_evaluation_system import TokenEvaluationSystem

# Создание системы с кастомной конфигурацией
config = {
    'discovery': {
        'min_market_cap': 2000000,
        'max_age_days': 21
    },
    'evaluation': {
        'security_weight': 0.5,
        'liquidity_weight': 0.3,
        'community_weight': 0.2
    }
}

system = TokenEvaluationSystem(config)

# Запуск полного цикла
await system.run_full_evaluation_cycle()

# Получение отчета
report = system.get_summary_report()
```

## ⚙️ Конфигурация

Основные настройки находятся в файле `config.yaml`:

```yaml
# Критерии обнаружения
discovery:
  filters:
    min_market_cap_usd: 1000000    # $1M
    max_age_days: 30
    min_holders: 100
    min_transactions: 1000

# Веса для оценки
evaluation:
  weights:
    security: 0.4
    liquidity: 0.3
    community: 0.3

# Интервалы мониторинга
monitoring:
  update_intervals:
    new_tokens_minutes: 30
    liquidity_minutes: 15
```

## 📊 Метрики и отчеты

### Основные метрики

1. **Безопасность**:
   - Верификация контракта
   - Наличие аудита
   - Мультисиг кошелек
   - Таймлок функции
   - Рискованные функции (mint, pause, blacklist)

2. **Ликвидность**:
   - Общая ликвидность в USD
   - Распределение по DEX
   - Концентрация ликвидности
   - Влияние на цену при сделках

3. **Сообщество**:
   - GitHub активность (звезды, форки, контрибьюторы)
   - Присутствие в социальных сетях
   - Качество документации
   - Размер сообщества

### Форматы отчетов

- **CSV**: Для анализа в Excel/Google Sheets
- **JSON**: Для программной обработки
- **Excel**: Комплексные отчеты с графиками
- **Веб-интерфейс**: Интерактивные дашборды (в разработке)

## 🚨 Обнаружение скам-токенов

### Красные флаги

- Неверифицированный контракт
- Функция `mint()` с правами владельца
- Функция `pause()` для остановки торгов
- Функция `blacklist()` для блокировки адресов
- Высокая концентрация токенов у владельца
- Подозрительные имена/символы
- Отсутствие документации
- Низкая ликвидность

### Зеленые флаги

- Верифицированный контракт
- Проведенный аудит безопасности
- Мультисиг кошелек
- Таймлок функции
- Открытый исходный код
- Активное сообщество
- Хорошая документация
- Распределенная ликвидность
